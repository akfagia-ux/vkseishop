# Настройка Firebase Authentication для Vkesi Shop

## ✅ Что уже сделано:
- Firebase SDK подключен к сайту
- Конфигурация Firebase настроена
- Система регистрации и входа работает с Firebase Authentication
- Обработка ошибок на русском языке

## 🔧 Что нужно сделать:

### 1. Включить Email/Password авторизацию в Firebase Console

1. Перейди на [Firebase Console](https://console.firebase.google.com/)
2. Выбери свой проект **vkseishop**
3. В левом меню выбери **Authentication** (Аутентификация)
4. Перейди на вкладку **Sign-in method** (Способ входа)
5. Найди **Email/Password** в списке провайдеров
6. Нажми на него и включи переключатель **Enable** (Включить)
7. Нажми **Save** (Сохранить)

### 2. Включить Google авторизацию в Firebase Console

1. В той же вкладке **Sign-in method** найди **Google**
2. Нажми на него
3. Включи переключатель **Enable** (Включить)
4. Выбери **Project support email** (email поддержки проекта)
5. Нажми **Save** (Сохранить)

### 3. Настроить домены для авторизации

1. В разделе **Authentication** → **Settings** (Настройки)
2. Перейди на вкладку **Authorized domains** (Авторизованные домены)
3. Добавь свой домен GitHub Pages:
   - `твой-username.github.io`
4. Нажми **Add domain** (Добавить домен)

### 4. Загрузить файлы на GitHub

Загрузи обновленные файлы:
- `index.html` (с Firebase SDK)
- `workers.html` (с Firebase SDK)
- `script.js` (с Firebase Authentication)
- `firebase-config.js` (конфигурация)

## 🎯 Как работает система:

### Регистрация через Email:
1. Пользователь вводит email и пароль (минимум 6 символов)
2. Firebase создает аккаунт
3. Автоматический вход после регистрации
4. Email пользователя отображается в навигации

### Вход через Email:
1. Пользователь вводит email и пароль
2. Firebase проверяет данные
3. При успехе - вход выполнен
4. При ошибке - показывается сообщение на русском

### Вход через Google:
1. Пользователь нажимает "Войти через Google"
2. Открывается всплывающее окно Google
3. Выбор аккаунта Google
4. Автоматический вход
5. Имя пользователя отображается в навигации

### Выход:
1. Нажатие кнопки "Выйти" в профиле
2. Firebase выполняет выход
3. Интерфейс обновляется

## 🔒 Безопасность:

- Пароли хранятся в зашифрованном виде в Firebase
- Используется официальный Firebase Authentication
- Автоматическая защита от брутфорса
- Проверка email формата
- Минимальная длина пароля - 6 символов

## ⚠️ Возможные ошибки:

### Email/Password авторизация:

**"auth/network-request-failed"**
- Проблема с интернет-соединением
- Отключи VPN/Cloudflare WARP
- Проверь, что домен добавлен в Authorized domains

**"auth/email-already-in-use"**
- Пользователь с таким email уже зарегистрирован
- Используй другой email или войди

**"auth/wrong-password"**
- Неверный пароль
- Проверь правильность ввода

**"auth/user-not-found"**
- Пользователь не найден
- Сначала зарегистрируйся

### Google авторизация:

**"auth/popup-closed-by-user"**
- Окно входа было закрыто до завершения
- Попробуй снова

**"auth/popup-blocked"**
- Браузер заблокировал всплывающее окно
- Разреши всплывающие окна для сайта

**"auth/cancelled-popup-request"**
- Запрос был отменен
- Попробуй снова
