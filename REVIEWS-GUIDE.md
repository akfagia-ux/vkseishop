# 📝 Руководство по управлению отзывами

## 🎯 Что было сделано

Создана полноценная система управления отзывами с хранением в Firebase:

1. **Отзывы хранятся в Firebase** - все отзывы теперь в базе данных
2. **Автоматическое обновление** - новые отзывы появляются на сайте автоматически
3. **Админ-панель** - удобное управление отзывами
4. **Динамическое время** - время отзывов обновляется автоматически

## 🚀 Как использовать

### Шаг 1: Инициализация (один раз)

1. Откройте в браузере: `init-reviews.html`
2. Нажмите кнопку **"📥 Загрузить отзывы в Firebase"**
3. Дождитесь сообщения об успехе
4. Готово! Отзывы загружены в базу данных

### Шаг 2: Добавление новых отзывов

**Через админ-панель:**

1. Откройте `admin.html`
2. Перейдите на вкладку **"⭐ Отзывы"**
3. Заполните форму:
   - **Имя пользователя**: например, "ProGamer2024"
   - **Текст отзыва**: например, "Отличный сервис!"
   - **Услуга и цена**: например, "Discord, 10 ₽"
4. Нажмите **"✅ Добавить отзыв"**
5. Отзыв сразу появится на главной странице!

### Шаг 3: Просмотр и удаление отзывов

1. В админ-панели на вкладке **"⭐ Отзывы"**
2. Нажмите **"🔄 Обновить список"**
3. Увидите все отзывы с кнопками удаления
4. Для удаления нажмите **"🗑️ Удалить"** рядом с отзывом

## 📊 Как это работает

### Автоматическое обновление

- Отзывы загружаются из Firebase при открытии главной страницы
- Время отзывов обновляется каждую минуту
- Новые отзывы появляются автоматически

### Формат времени

Система автоматически показывает:
- "только что" - если меньше минуты
- "5 минут назад" - если меньше часа
- "2 часа назад" - если меньше дня
- "3 дня назад" - если меньше недели
- И так далее...

Формат: **"18 февраля в 18:13, 2 дня назад"**
