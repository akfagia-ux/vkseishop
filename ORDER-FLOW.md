# Процесс оформления заказа - Vkesi Shop

## Полный процесс от заказа до отзыва (через ЛС на сайте)

### 1. Оформление заказа (order.html)

Пользователь заходит на страницу услуг и нажимает "Заказать" на карточке "Скрипт на деморган GTA 5 RP".

**Форма заказа:**
- Имя
- Фамилия  
- Email (необязательно)

**Что происходит:**
- Создается документ в коллекции `orders` в Firebase
- Статус: `pending`
- Если пользователь авторизован, сохраняется его `userId`
- Пользователь перенаправляется на `payment.html?orderId=XXX`

### 2. Страница оплаты (payment.html)

**Отображается:**
- Информация о заказе (товар, покупатель, сумма)
- Номер телефона для перевода: **+7 921 804 85 83**
- Предупреждение о необходимости оплаты
- Кнопка "Я оплатил"

**Действия пользователя:**
1. Переводит деньги на указанный номер через СБП/банк
2. Нажимает "Я оплатил"

**Что происходит:**
- Обновляется заказ: `paymentConfirmed: true`
- Добавляется уведомление в общий чат на сайте
- Создается (или находится существующий) чат между покупателем и владельцем
- Отправляется сообщение владельцу в ЛС с деталями заказа
- Пользователь перенаправляется на страницу сообщений (messages.html)

### 3. Личные сообщения на сайте

**Уведомление владельцу в ЛС:**
```
🔔 Новый заказ!

🆔 ID: order_id
👤 Покупатель: Имя Фамилия
📦 Товар: Скрипт на деморган GTA 5 RP
💰 Сумма: 100₽
📧 Email: email@example.com

⚠️ Проверьте поступление оплаты на номер +79218048583

После выполнения заказа подтвердите его в админ-панели.
```

**Покупатель может:**
- Написать владельцу в ЛС
- Задать вопросы
- Уточнить детали

### 4. Выполнение заказа (через админ-панель)

**Владелец:**
1. Получает уведомление в ЛС на сайте
2. Проверяет поступление денег на номер +79218048583
3. Выполняет заказ (отправляет скрипт покупателю через ЛС)
4. Открывает админ-панель → вкладка "Заказы"
5. Нажимает кнопку "✅ Выполнить" напротив заказа

**Что происходит:**
- Обновляется заказ: `completed: true`
- Покупатель получает уведомление в ЛС:
```
✅ Ваш заказ выполнен!

📦 Скрипт на деморган GTA 5 RP
💰 100₽

Спасибо за покупку! Покупайте чаще у нас! 🎉

⭐ Оставьте отзыв о покупке:
https://vkesi-shop.com/leave-review.html?orderId=XXX
```

### 5. Отзыв (leave-review.html)

**Страница отзыва:**
- Информация о заказе (товар, сумма)
- Выбор оценки (1-5 звезд)
- Текстовое поле для отзыва (минимум 10 символов)

**Что происходит:**
- Отзыв добавляется в коллекцию `reviews`
- Заказ обновляется: `reviewSubmitted: true`
- Отзыв появляется на главной странице (index.html)
- Пользователь перенаправляется на главную страницу

## Структура данных Firebase

### Коллекция `orders`

```javascript
{
  // Информация о покупателе
  firstName: "Иван",
  lastName: "Иванов",
  email: "ivan@example.com",
  userId: "user_firebase_id", // Если авторизован
  
  // Информация о товаре
  productName: "Скрипт на деморган GTA 5 RP",
  productId: "gta_script",
  amount: 100,
  
  // Статусы
  status: "pending",
  paymentConfirmed: false,
  completed: false,
  reviewSubmitted: false,
  
  // Чат
  chatId: "chat_id", // ID чата с владельцем
  
  // Временные метки
  createdAt: Timestamp,
  paymentConfirmedAt: Timestamp,
  completedAt: Timestamp,
  reviewSubmittedAt: Timestamp
}
```

### Коллекция `chats`

```javascript
{
  type: "direct",
  participants: ["owner_id", "buyer_id"],
  createdAt: Timestamp,
  lastMessage: "Текст последнего сообщения",
  lastMessageTime: Timestamp,
  unreadCount: {
    owner_id: 1,
    buyer_id: 0
  }
}
```

### Подколлекция `chats/{chatId}/messages`

```javascript
{
  text: "Текст сообщения",
  userId: "user_id" или "system",
  displayName: "Имя пользователя" или "Система",
  timestamp: Timestamp
}
```

### Коллекция `reviews`

```javascript

```

## Важные моменты

### Безопасность
- Всегда проверяйте поступление оплаты перед выполнением заказа
- Номер для оплаты: **+7 921 804 85 83**
- Не выполняйте заказы без подтверждения оплаты

### Поддержка
- Все общение через ЛС на сайте
- Покупатель может написать владельцу в любой момент
- Владелец получает уведомления о новых сообщениях

### Отзывы
- Отзыв можно оставить только после выполнения заказа
- Один отзыв на один заказ
- Отзыв показывает сумму заказа и оценку (1-5 звезд)

## Админ-панель

### Вкладка "Заказы"

Показывает все заказы с информацией:
- ID заказа
- Покупатель (имя, фамилия)
- Товар
- Сумма
- Статус (ожидает оплаты / ожидает выполнения / выполнен)
- Дата создания
- Действия (кнопка "Выполнить", кнопка "Просмотр деталей")

### Действия владельца:

1. **Просмотр деталей** (👁️) - показывает полную информацию о заказе
2. **Выполнить** (✅) - подтверждает выполнение заказа и отправляет уведомление покупателю

## Настройка

### Firebase Rules

Убедитесь, что правила разрешают:
- Создание заказов
- Обновление статусов заказов
- Создание чатов и сообщений
- Создание отзывов
- Чтение заказов по ID

## Тестирование

1. Оформите тестовый заказ на сайте
2. Проверьте создание документа в Firebase
3. Подтвердите "оплату"
4. Проверьте уведомление в ЛС владельцу
5. Откройте админ-панель → Заказы
6. Подтвердите выполнение
7. Проверьте уведомление покупателю в ЛС
8. Оставьте тестовый отзыв
9. Проверьте отображение отзыва на главной странице

## Преимущества системы ЛС

- Все общение в одном месте (на сайте)
- Не нужно устанавливать Telegram
- История переписки сохраняется
- Владелец видит все заказы в админ-панели
- Покупатель может задать вопросы до и после покупки
