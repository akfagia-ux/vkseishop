## Быстрый старт

### Шаг 1: Настройте Telegram бота

1. Откройте Telegram и найдите @BotFather
2. Отправьте `/newbot`
3. Имя: `Vkesi Pay`
4. Username: `vkesi_pay` (или другой доступный)
5. Скопируйте токен бота

### Шаг 2: Узнайте свой Telegram ID

1. Найдите @userinfobot в Telegram
2. Отправьте `/start`
3. Скопируйте ваш ID

### Шаг 3: Настройте Firebase

1. Откройте Firebase Console: https://console.firebase.google.com
2. Выберите проект `vkseishop`
3. Перейдите в Project Settings → Service Accounts
4. Нажмите "Generate new private key"
5. Скачайте JSON файл

### Шаг 4: Создайте .env файл

В папке `telegram-bot` создайте файл `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
FIREBASE_PROJECT_ID=vkseishop
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nВаш\nКлюч\n-----END PRIVATE KEY-----\n"
FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxxxx@vkseishop.iam.gserviceaccount.com
OWNER_ID=ваш_telegram_id
```

**Важно:** 
- `FIREBASE_PRIVATE_KEY` должен быть в кавычках
- Сохраните `\n` как есть (не заменяйте на реальные переносы строк)

### Шаг 5: Установите зависимости

```bash
cd telegram-bot
npm install
```

### Шаг 6: Запустите бота

```bash
npm start
```

Вы должны увидеть: `🤖 Бот запущен и слушает новые заказы!`

## Проверка работы

### Тест 1: Создание заказа
1. Откройте http://localhost:8000/order.html (или ваш домен)
2. Заполните форму
3. Проверьте, что создался документ в Firebase → orders

### Тест 2: Страница оплаты
1. После создания заказа должна открыться payment.html
2. Проверьте, что отображается номер телефона
3. Проверьте, что кнопка "Открыть Telegram бот" работает

### Тест 3: Telegram бот
1. Откройте бота @vkesi_pay (или ваш username)
2. Отправьте `/start`
3. Должно появиться приветствие

### Тест 4: Связывание заказа
1. Откройте ссылку из payment.html (с orderId)
2. Бот должен сказать "Заказ успешно связан"

### Тест 5: Уведомление владельцу
1. Нажмите "Я оплатил" на странице оплаты
2. Вы должны получить уведомление в Telegram
3. Должна быть кнопка "Подтвердить выполнение"

### Тест 6: Выполнение заказа
1. Нажмите кнопку в боте
2. Покупатель должен получить уведомление
3. В уведомлении должна быть ссылка на отзыв

### Тест 7: Отзыв
1. Откройте ссылку на отзыв
2. Выберите оценку (1-5 звезд)
3. Напишите текст отзыва
4. Отправьте
5. Проверьте, что отзыв появился на главной странице

## Troubleshooting

### Бот не запускается
- Проверьте BOT_TOKEN в .env
- Убедитесь, что установлены зависимости: `npm install`
- Проверьте Node.js версию: `node --version` (должна быть 18+)

### Не приходят уведомления
- Проверьте OWNER_ID в .env
- Убедитесь, что бот запущен
- Проверьте логи в консоли

### Ошибка Firebase
- Проверьте FIREBASE_PRIVATE_KEY (должен быть в кавычках)
- Проверьте Firebase Rules (должны разрешать запись)
- Проверьте, что проект называется vkseishop

### Покупатель не получает уведомление
- Убедитесь, что он открыл бота через ссылку с orderId
- Проверьте, что telegramChatId сохранился в заказе
- Проверьте логи бота
